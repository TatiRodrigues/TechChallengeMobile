# Checklist de execução do projeto

## Ambiente
- [ ] Node.js 18+ instalado
- [ ] npm disponível
- [ ] Projeto clonado ou localizado na pasta correta
- [ ] Dependências instaladas com `npm install`
- [ ] Arquivo `.env` criado com as chaves do Firebase

## Firebase
- [ ] Projeto criado no Firebase Console
- [ ] Authentication habilitado com e-mail/senha
- [ ] Firestore habilitado
- [ ] Storage habilitado
- [ ] Chaves do app web copiadas para o `.env`

## Execução
- [ ] Comando `npx expo start --clear` rodou sem erro
- [ ] App abriu em emulador ou no Expo Go
- [ ] Login funcionou
- [ ] Dashboard apareceu
- [ ] Transações carregaram
- [ ] Filtros funcionaram
- [ ] Cadastro de transação funcionou
- [ ] Edição funcionou
- [ ] Upload de anexo funcionou
- [ ] Firestore recebeu as transações
- [ ] Storage recebeu os arquivos anexados

## Observações finais
- [ ] Fluxo completo validado
- [ ] Encaminhar para entrega final
- [ ] Gravar o vídeo demonstrativo se necessário
